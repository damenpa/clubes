# 🏕️ Management System

A **Spring Boot** web application designed to manage **Pathfinder clubs**, including members, churches, and classes.  
It provides secure authentication, CRUD operations, and database persistence using **MySQL** and **Spring Data JPA**.

---

## 🚀 Features

- 🔐 **User Authentication & Password Encryption** — Secure login with BCrypt password hashing.
- 🧑‍🤝‍🧑 **Pathfinder Management** — Create, update, view, and delete club members.
- 🧱 **RESTful API** — Fully functional backend exposing endpoints for integration or frontend use.
- 💾 **MySQL Database Integration** — Data persistence using Spring Data JPA repositories.
- ⚙️ **DTO Mapping** — Uses DTOs and `ObjectMapper` for data transfer and validation.
- 🧩 **Layered Architecture** — Clean separation of Controller, Service, and Repository layers.
